Brute Force Security Incident Report Lab

## Objective
Given a scenario, document the security incident in detail, including idetifying network protocols used to establish the connection between the user and the website, as well as recommend a security action to prevent brute force attacks in the future.

### Skills Learned


- Packet Capture Analysis: Interpreted raw tcpdump network log outputs to trace DNS requests, TCP connection handshakes, and http packet sequences.
- Web Server Security Assessment: Evaluated web application code vulnerabilities and identified administrative account entry points exploited via credential guessing.
- Identity & Access Management (IAM) Hardening: Formulated password policy recommendations and Multi-Factor Authentication (MFA) strategies to mitigate brute-force vulnerabilities.
### Tools Used

- Tcpdump(CLI): Used to capture and read network traffic logs, inspecting DNS queries and HTTP request headers.
- Incident Report Documentation: Applied standardized incident response templates to document attack timelines, root causes, and remediation steps.
